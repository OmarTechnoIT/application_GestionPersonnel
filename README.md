# 👨‍💼 Application de Gestion du Personnel

## 📖 Description
Cette application permet de gérer les employés d’une organisation : informations personnelles, postes, départements et suivi administratif.

Le projet a été développé dans le cadre de mes travaux en développement logiciel et gestion des systèmes d’information.

---

## ⚙️ Fonctionnalités
- Ajout, modification et suppression des employés
- Gestion des départements et postes
- Recherche et filtrage du personnel
- Interface utilisateur simple et intuitive
- Gestion locale des données

---

## 🧰 Technologies utilisées
- Embarcadero Delphi XE7
- Windows 10 / 11
- Base de données locale
